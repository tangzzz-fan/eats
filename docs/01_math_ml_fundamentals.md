## 重难点速览

| 重难点 | 一句话要点 | 易错/关键提示 |
| --- | --- | --- |
| 向量/矩阵/张量 | 本质就是不同维度的多维数组 | 向量 Shape 是 `(3,)`（单元素元组），不是 `(3, 1)` |
| 广播 (Broadcasting) | 从右往左对齐维度，相等或一方为 `1` 即可逐元素计算 | 两个数组要各加一个轴（`[:, np.newaxis, :]` 和 `[np.newaxis, :, :]`），位置加错结果全错 |
| K-Means 收敛 | 反复执行「算距离 → 归类 → 移动中心」，直到中心不再移动 | 初始中心是随机选的，不同初始化可能得到不同聚类结果 |
| 前向填充 (`.ffill()`) | 用上一时刻的有效值填补空缺时间段 | 别用 `0` 填充——物理量（车速、温度）不会瞬间归零 |
| 时序划分 (No Shuffle) | 只能按时间顺序切分训练/测试集 | 随机打散会让未来信息泄露到训练集，产生虚假高准确率 |

## 1. 线性代数的程序员视角：从列表到张量 (Tensor)

在 Python 中，你非常熟悉列表（List）。线性代数中的标量、向量、矩阵和张量，本质上就是**多维数组的数据结构**。

### 1.1 一维：向量 (Vector)
* **Python 表示**：`[1.0, 2.0, 3.0]` (长度为 3 的一维列表)
* **物理/数学含义**：包含多个方向特征的一条线。比如一个人的属性 `[年龄 25, 身高 175, 体重 70]`。
* **Shape (形状)**：`(3,)`
  * 注意：`(3,)` 是**只含一个元素的元组**（Python 中 `(3)` 只是数字 3，必须带逗号才是元组）。在 NumPy 中向量不分「行向量/列向量」，一维数组的 Shape 一律是 `(n,)`，只有显式 `reshape(3, 1)` 才会变成二维的列向量。

### 1.2 二维：矩阵 (Matrix)
* **Python 表示**：嵌套列表 `[[1, 2], [3, 4], [5, 6]]`
* **物理/数学含义**：表格数据。**行 (Row)** 代表不同的样本，**列 (Column)** 代表不同的特征。
* **Shape (形状)**：`(3, 2)`（3 个样本，每个样本有 2 个特征）。

### 1.3 三维及以上：高维张量 (Tensor)
* **物理/数学含义**：
  * **3D 张量 `(N, K, D)`**：比如 $N$ 个数据点，每个点到 $K$ 个中心点，每个对比有 $D$ 个特征差值（正是 Day 06 K-Means 中的 3D 广播矩阵）。
  * **3D 文本张量 `(Batch, Seq_Len, Dim)`**：比如一个 Batch 有 32 句话，每句话有 10 个词，每个词用 512 维向量表示。

## 2. 向量化与广播机制 (Broadcasting)

### 2.1 为什么需要向量化？
在 Python 中，用 `for` 循环对 100 万个数据做平方计算需要花费几秒钟；而在 NumPy 中直接 `arr ** 2` 只需要几毫秒。
* **原因**：Python 列表里存的是对象的指针，每次循环都需要动态查找类型；而 NumPy 数组在内存中是连续存放的 C 语言原生数据，CPU 可以并行指令处理（SIMD）。

### 2.2 广播 (Broadcasting) 的核心对齐规则

广播是 NumPy / PyTorch 最神奇的能力：**让维度不匹配的两个数组自动补齐并做逐元素计算**。

**记忆口诀**：“**从右往左看，相等或有 1 就能对上**”。

#### 经典案例：
如果有 5 个点，Shape 为 `(5, 2)`；3 个中心点，Shape 为 `(3, 2)`。怎么一口气算完 5 个点到 3 个中心的距离？

1. **扩展维度**：
   * `points[:, np.newaxis, :]` $\rightarrow$ Shape: `(5, 1, 2)`
   * `centers[np.newaxis, :, :]` $\rightarrow$ Shape: `(1, 3, 2)`
2. **从右往左对比维度**：
   * 最右边（特征维）：都是 `2` $\rightarrow$ 匹配
   * 中间（中心维）：一个是 `1`，一个是 `3` $\rightarrow$ 自动将 `1` 复制扩展 3 次
   * 最左边（样本维）：一个是 `5`，一个是 `1` $\rightarrow$ 自动将 `1` 复制扩展 5 次
3. **相减结果**：Shape 自动变为 `(5, 3, 2)`，包含了 $5 \times 3 = 15$ 对点的坐标差。

对应的完整代码只需 3 行（这也正是 Day 06 K-Means 算距离的核心）：

```python
import numpy as np
diff = points[:, np.newaxis, :] - centers[np.newaxis, :, :]  # Shape: (5, 3, 2)
distances = np.sqrt((diff ** 2).sum(axis=-1))                # Shape: (5, 3)，沿最后一维（特征维）求和
```

## 3. 无监督学习：K-Means 聚类直观理解

### 3.1 什么是聚类？
想象你有一堆没有标签的果实，你不知道它们的名字。但你可以根据“重量”和“甜度”两个指标，把它们在二维坐标系上打点。
* 距离近的果实，大概率属于同一品种。
* **聚类的目标**：在没有老师（标签 $Y$）指导的情况下，自动把相似的数据分成 $K$ 个组（Cluster）。

### 3.2 K-Means 4 步循环法则

```text
[1. 随机选点] ──> 在所有数据中随机挑选 K 个点作为初始“聚类中心”
      │
      ▼
[2. 计算距离] ──> 计算每个数据点到这 K 个中心的欧氏距离 (Broadcasting)
      │
      ▼
[3. 归类划界] ──> 每个数据点选择距离自己最近的中心，加入该组 (np.argmin)
      │
      ▼
[4. 移动中心] ──> 计算每个组内所有成员的平均坐标，将中心移动到均值位置 (mean)
      │
      ▼
[循环反复] ────> 重复 2-4 步，直到中心点位置不再移动（收敛）
```

## 4. 时间序列数据工程 (Time Series Pipeline)

时间序列（如股票、传感器数据）与普通表格数据最大的区别是：**时间不可倒流，前后行之间有强烈相关性**。

### 4.1 重采样 (Resampling) 与 前向填充 (Forward Fill)
* **问题**：传感器发送数据的频率可能极不规律（有时 1 秒发送一次，有时 5 秒发送一次）。
* **重采样 (`df.resample('10s').mean()`)**：按固定时间网格（如每 10 秒）做聚合，把数据切成规整的“时间段”。
* **前向填充 (`.ffill()`)**：如果某个 10 秒段内没采到数据，用**上一时刻的有效数值**填补。因为物理世界中，车速、温度不会突然消失变 0，保持上一时刻的值最符合物理逻辑。

### 4.2 历史特征构造：滑动窗口 (Rolling) 与 时滞 (Lag)

如何让模型预测“未来”？必须给模型提供“历史记忆”！

* **滑动窗口 (`rolling(window=3).mean()`)**：
  计算过去 3 个时刻的平均值。能帮模型平滑掉随机噪声，看清短期趋势。
* **时滞特征 (`shift(1)`, `shift(2)`)**：
  把数据整体向后推 $1$ 行和 $2$ 行，作为新的列 `lag_1`, `lag_2`。这样在 $t$ 时刻，模型就能同时看到 $t-1$ 和 $t-2$ 时刻的数据。
  * 注意：`shift(n)` 后**前 $n$ 行没有历史数据，会变成 `NaN`**；同理 `rolling(window=3)` 的前 2 行也是 `NaN`。构造完特征后通常要 `df.dropna()` 丢掉开头这几行，否则模型训练时会报错。

### 4.3 时间序列划分防偷看原则 (No Shuffle)
* **常规机器学习**：随机打散划分 `train_test_split(shuffle=True)`。
* **时间序列划分**：**绝对禁止随机打散**！只能按时间切一刀：前 80% 作为训练集，后 20% 作为测试集。否则未来信息会泄露给过去，产生虚假的超高准确率。
