## 重难点速览

| 重难点 | 一句话要点 | 易错/关键提示 |
| --- | --- | --- |
| 欧拉一阶数值积分 | 用「当前速度 × $\Delta t$」近似这步内的位移，逐步递推位姿 | $\Delta t$ 取得过大，轨迹会明显偏离真实弧线；仿真中常用 `dt = 0.05` 量级 |

## 1. 什么是具身智能与物理仿真？

* **传统 AI（如 ChatGPT）**：纯文本/图像的软智能，运行在数字世界里。
* **具身智能 (Embodied AI)**：拥有物理实体（如移动机器人、机械臂），需要在物理世界中感知环境、规划路径，并通过电机执行动作。
* **物理仿真器**：在计算机中用数学公式模拟真实物理世界（位置、速度、摩擦力等），方便算法快速迭代验证。

## 2. 2D 差速移动机器人运动学 (Kinematics)

### 2.1 状态向量 (State)
在二维平面中，一个移动小车的状态可以用 3 个变量构成的三元组完全描述：
$$\boldsymbol{x} = (x, y, \theta)$$
* $x, y$：小车在平面直角坐标系中的位置（单位：米 $m$）。
* $\theta$（航向角 Yaw）：小车车头当前指向的角度（单位：弧度 $rad$）。

---

### 2.2 控制输入 (Control Inputs)
小车由底盘电机驱动，接收两个控制指令：
* $v$：线速度（前进/后退速度，单位：$m/s$）。
* $\omega$：角速度（原地旋转/转向速度，单位：$rad/s$）。

---

### 2.3 欧拉一阶数值积分 (Euler Integration)

当给定一个微小的时间步长 $\Delta t$（例如 $dt = 0.05$ 秒）时，小车在下一个时刻的新位置通过以下离散递推公式计算：

$$x_{new} = x + v \cdot \cos(\theta) \cdot \Delta t$$
$$y_{new} = y + v \cdot \sin(\theta) \cdot \Delta t$$
$$\theta_{new} = \theta + \omega \cdot \Delta t$$

#### 通俗解释：
* 小车沿着当前车头方向 $\theta$ 移动，速度在 $X$ 轴上的投影分量是 $v \cos(\theta)$，在 $Y$ 轴上的投影分量是 $v \sin(\theta)$。
* 乘以时间步长 $dt$，就得到这 $dt$ 秒内小车在 $X$ 和 $Y$ 方向上挪动的距离。

> 为什么叫「一阶」？因为它假设整个 $dt$ 内速度保持当前值不变（只做线性外推），忽略了步长内转向带来的弧线弯曲。所以 $\Delta t$ 越小逼近越准，取得过大会让转弯轨迹明显失真。

## 3. 经典反馈控制：PID 控制器原理

机器人不可能凭空“瞬间变到”目标位置，必须根据当前位置与目标位置的**误差 (Error)**，不断计算输出合理的线速度 $v$ 或角速度 $\omega$。这就是 **PID 闭环控制**。

$$\text{Output} = K_p \cdot e(t) + K_i \int e(t) dt + K_d \cdot \frac{de(t)}{dt}$$

```text
       ┌──────────┐   误差 e(t)   ┌────────────┐   控制输出 u(t)  ┌──────────┐
目标 ──>│ 减法器 ├──────────────>│ PID 控制器 ├────────────────>│ 机器人   │
       └────▲─────┘              └────────────┘                 └────┬─────┘
            │                        反馈当前状态 (x, y, θ)           │
            └────────────────────────────────────────────────────────┘
```

### 3.1 P、I、D 三项的物理直观含义

1. **比例项 $P$ (Proportional - 响应当前)**：
   * 误差越大，输出控制力越大。比如距离目标 10 米时踩大油门，距离 0.1 米时踩小油门。
2. **积分项 $I$ (Integral - 消除累积静差)**：
   * 把历史上的所有残余误差累加起来 (`integral += error * dt`)。如果小车因为地面摩擦力大停在了目标点前 0.01 米处，$P$ 项作用太弱无法推倒小车，此时 $I$ 项随着时间累加会越来越大，最终推倒小车彻底消除残余误差。
3. **微分项 $D$ (Derivative - 预测未来/平抑震荡)**：
   * 测量误差的变化率（刹车阻尼器）。当小车以极高速度飞快接近目标时，微分项会施加反向力（提前刹车），防止小车冲过头产生剧烈来回震荡。
   * 离散实现时用相邻两次误差之差除以 `dt` 近似导数：
     ```python
     derivative = (error - prev_error) / dt
     prev_error = error  # 更新缓存，供下一拍使用
     ```

## 4. 机器人工程中的两大“致命陷阱”与解决方案

### 4.1 陷阱一：角度跨越不连续与原地猛甩头 (Angle Wrap-Around)

#### 问题描述：
弧度制的范围是 $[-\pi, \pi]$（即 $[-180^\circ, 180^\circ]$）。
假设小车当前朝向是 $-179^\circ$（$-3.12$ rad），目标方向是 $179^\circ$（$3.12$ rad）。
物理上，小车**只需要往反方向顺时针转 $2^\circ$** 就能对准目标。

但是，如果你直接用常规减法计算角度误差：
$$\text{error} = 179^\circ - (-179^\circ) = 358^\circ$$
PID 控制器看到高达 $358^\circ$ 的巨幅误差，会认为小车偏离了极大，从而命令小车**逆时针猛转 358 度**！导致小车原地猛烈抽搐甩头。

#### ✅ 解决方案：利用 `atan2` 进行角度归一化
```python
import math

# 将任何超出范围的角度差归一化映射到 [-pi, pi] 主值区间
angle_diff = target_theta - current_theta
normalized_error = math.atan2(math.sin(angle_diff), math.cos(angle_diff))
```
通过 `atan2(sin, cos)` 转换后，`358°` 会被自动修正为正确的最短转向误差 `-2°`（$-0.035$ rad）！

原理一句话：`sin` 和 `cos` 都以 $2\pi$ 为周期，角度差里多出的整圈数（$358^\circ$ 与 $-2^\circ$ 相差整 $360^\circ$）会被自动丢掉；`atan2` 再根据两者的符号把结果还原到 $[-\pi, \pi]$ 主值区间，且不会像 `atan` 那样丢失象限信息。

---

### 4.2 陷阱二：积分饱和与跑飞 (Integral Windup)

#### 问题描述：
当小车距离目标非常远（比如 100 米外）时，在漫长的奔跑过程中，`self.integral += error * dt` 每一秒都在巨量累加。
当小车终于到达目标点时，积分项累积的数值已经膨胀到了上千！即使当前距离误差变成了 0，巨大的积分值仍然会让小车无法停止，一路猛冲过头。

#### ✅ 解决方案：限制积分上下限 (Anti-Windup Clamping)
```python
# 对累积积分加上硬性上下限裁剪 (Clamp)
self.integral += error * dt
max_integral = 1.0
self.integral = max(-max_integral, min(self.integral, max_integral))
```
或者限制仅在靠近目标（误差较小）时才开启积分累加。
